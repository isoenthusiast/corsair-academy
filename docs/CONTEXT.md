# Gamified Learning — Design Philosophy & Domain Language

**Last Reviewed:** July 26, 2026 (Phase 5 documentation audit — accurate)

## Core Purpose

A platform that makes learning **irresistible** for kids. Not "educational software" — a game where the side effect is knowledge.

## Domain Glossary

| Term | Definition |
|------|-----------|
| **Quest** | A learning module — a set of challenges around one topic (e.g., "Fractions Basics") |
| **Challenge** | A single question, puzzle, or task within a quest |
| **Streak** | Consecutive days with at least one completed challenge |
| **Mastery** | Proven competence — 3 consecutive correct answers on a topic without hints |
| **Power-Up** | Unlockable helper (hint, skip, double points) earned through streaks |
| **XP** | Experience points — the universal progress currency |
| **Star** | Rating per challenge (1-3 stars based on accuracy + speed) |
| **World** | A subject area (Math, Science, Language, Logic) |
| **Boss Level** | A cumulative challenge at the end of a quest — must pass to unlock next quest |
| **Adventure Path** | The recommended sequence of quests through a world |

## Octalysis Core Drives (Gamification Framework)

| Drive | How It's Applied |
|-------|-----------------|
| **CD1: Epic Meaning** | "You're not just learning math — you're training to be a Problem Solver" |
| **CD2: Development** | Visible progress bars, level-ups, mastery badges |
| **CD3: Empowerment** | Creative challenges, open-ended puzzles, "build your own question" |
| **CD4: Ownership** | Custom avatar, collectible items, personal learning dashboard |
| **CD5: Social Influence** | (Future) Friend challenges, shared quests, parent-child co-play |
| **CD6: Scarcity** | Power-ups are earned, not given. Rare badges for exceptional performance |
| **CD7: Curiosity** | Mystery quests, surprise bonus rounds, "what's behind this door?" |
| **CD8: Loss Avoidance** | Streak protection (1 free skip per week), "don't lose your streak!" |

## Design Principles

1. **No failure — just "not yet"** — Wrong answers give hints, not red X's. Retry is encouraged.
2. **3-star system** — 1 star for completing, 2 for accuracy, 3 for speed + accuracy. Perfectionists can chase 3 stars; everyone passes.
3. **AI-generated variety** — Questions are never the same twice. AI creates fresh content adapted to the child's level.
4. **Short sessions** — Quests are 5-10 minutes. Designed for attention spans, not marathon study.
5. **Parent as coach, not enforcer** — Dashboard shows progress, struggles, and suggested conversation starters. Never "you failed 3 times."
6. **Offline-friendly** — Quests can be pre-loaded. Sync when back online.

## Age Target

Primary: Ages 7-12. Content difficulty adapts automatically. UI uses icons + text (no reading-heavy interfaces for younger kids).
